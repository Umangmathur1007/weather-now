# 🌤️ Weather Now

A simple React app that lets users check the current weather for any city using the **Open-Meteo API**.

## 👤 User Persona
**Jamie** — an outdoor enthusiast who wants to check weather conditions quickly.

## 🚀 Features
- Search any city
- Shows temperature, wind speed, and weather description
- Uses Open-Meteo API (no API key required)
- Responsive and modern design

## 🧠 Tech Stack
- React.js
- Axios
- CSS3
